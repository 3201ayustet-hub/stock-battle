# 株価成長バトル Ver.2.0

## 更新順序
1. Supabase SQL Editorで新しいタブを開く
2. `SUPABASE_UPDATE_v2.0.sql` の全文を貼り付けて実行
3. GitHubリポジトリのWebファイルをこのフォルダの内容へ置き換える

## 主な変更
- メイン画面を黒基調のダッシュボードへ刷新
- 不要な左上アイコン、共有URL、期間表示を削除
- 4人分をコンパクトに表示
- 終値入力を4人一括の省スペース表示へ変更
- 対戦設定ページで登録内容と大会ルールを編集可能
- 過去の対戦は別データとして保存
- 参加者ごとの途中利確、利確済み表示、終値入力停止
- 設定ページで利確情報の修正・取消が可能

## 注意
`config.js` は現在のSupabase接続情報を含みます。GitHub Pagesでそのまま使えます。
