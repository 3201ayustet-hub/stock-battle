# 株価成長バトル

4人がそれぞれ選んだ日本株について、購入価格からの成長率を比較するGitHub Pages向けWebアプリです。毎日の終値は4人の誰でも手入力できます。

## 機能

- 4人・1人1銘柄の対戦作成
- 推測しにくい共有URLの発行
- 毎日の終値を4銘柄まとめて登録
- 成長率ランキング
- Chart.jsによる折れ線グラフ
- 過去データの修正・削除
- JSONバックアップ
- スマートフォン対応
- ログイン不要

## 1. Supabaseを準備

1. Supabaseで新規プロジェクトを作成します。
2. SQL Editorを開きます。
3. `supabase/schema.sql` の内容をすべて貼り付け、実行します。
4. Project Settings → API から次を控えます。
   - Project URL
   - Publishable key（古いプロジェクトでは anon key）

`service_role`キーは絶対に使用しないでください。

## 2. アプリへ接続情報を設定

`js/config.js` を編集します。

```js
window.APP_CONFIG = {
  supabaseUrl: "https://YOUR_PROJECT.supabase.co",
  supabasePublishableKey: "YOUR_PUBLISHABLE_OR_ANON_KEY"
};
```

このPublishable/anon keyはブラウザで使うことを前提としたキーです。データ表への直接アクセスは無効化し、共有トークンを確認するSQL関数だけを公開しています。

## 3. GitHub Pagesで公開

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内のファイルをリポジトリ直下へアップロードします。
3. Settings → Pages を開きます。
4. Deploy from a branch を選びます。
5. `main` ブランチ、`/(root)` を選択して保存します。
6. 表示されたPages URLを開きます。

## 4. 使い方

1. 最初の画面で対戦名、期間、4人の情報を登録します。
2. 作成後のURLを4人に共有します。
3. 「終値入力」から取引日と4銘柄の終値を登録します。
4. ランキングとグラフが自動更新されます。
5. 入力ミスは「履歴」から修正できます。

## 注意事項

- URLを知っている人は閲覧・編集できます。SNSなどには公開しないでください。
- 配当、税金、手数料、買い増し、途中売却は計算に含みません。
- 株式分割・併合は初期版では自動補正しません。発生時は比較ルールを4人で決めてください。
- 終値は信頼できる同一の情報源から入力してください。
- 重要な節目では履歴ページからJSONバックアップを保存してください。
