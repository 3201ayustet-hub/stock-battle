# 株価成長バトル Ver.2.4

## 主な変更

- 設定タブの初期画面を「保存済みの対戦一覧」のみに変更
- 一覧の「設定」から、選択した大会の編集画面へ移動
- 「新しい対戦」から新規作成画面へ移動
- 保存後は保存済み一覧へ戻り、Supabaseの最新一覧を表示
- ランキングを今期成長率の高い順で表示
- 成長率同率時は今期損益、現在資産、登録順で順位を決定
- 終値入力シートの×ボタンは、必須項目が未入力でも即座に閉じる
- 背景部分のタップでも終値入力シートを閉じる
- ローカルCSS・JavaScriptにバージョン番号を付け、GitHub Pagesの古いキャッシュを回避

## 更新方法

1. ZIPを展開します。
2. GitHub Pages用リポジトリの既存ファイルを、展開したファイルで置き換えます。
3. GitHub Pagesの反映後、Safariでページを再読み込みします。
4. Ver.2.2以降のSQLを実行済みなら、追加のDB更新は不要です。

## 注意

アプリはSupabaseへ接続するため、実際のデータ取得・保存には `config.js` の設定とSupabase側のRPCが必要です。
