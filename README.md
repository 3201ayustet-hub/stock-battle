# 株価成長バトル Ver.1.2

4人分の日本株ポートフォリオを共有するGitHub Pages + Supabaseアプリです。

## 資産計算

- 開始時資産 = 購入価格 × 所有株数 + 繰越余剰金
- 現在資産 = 最新終値 × 所有株数 + 繰越余剰金
- 成長率 = (現在資産 - 開始時資産) ÷ 開始時資産 × 100
- 合計資産 = 4人の現在資産の合計

## 既存環境からの更新

1. Supabase SQL Editorで `migration-v1.2.sql` を一度実行
2. GitHub上のWebファイルを本フォルダの内容で置き換え
3. GitHub Pagesの反映後、`setup.html`から新しい対戦を作成

既存対戦には所有株数1株、繰越余剰金0円が自動設定されます。
