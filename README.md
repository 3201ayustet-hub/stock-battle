# 株価成長バトル Ver.2.1

## 更新手順
1. SupabaseのSQL Editorで `SUPABASE_UPDATE_v2.1.sql` 全文を実行
2. GitHubリポジトリのWebファイルをこのフォルダの内容で置き換え
3. GitHub Pagesを再読み込み（古い表示の場合はSafariのタブを閉じて開き直す）

## 主な変更
- 最後に開いた対戦を自動復元し、ダッシュボードをトップ表示
- 現在資産合計・今期損益・通算損益・最新更新を表示
- 設定に初期資産額を追加
- 終値入力をメイン画面のボトムシート化
- 参加者カードを簡潔にし、詳細はタップで展開
- 利確、利確取消、利確情報修正
- JSON保存機能を削除
- 設定画面を大会・参加者・ルール・管理に整理

## 計算
- 今期損益 = Σ((現在値または売却価格 − 取得単価) × 株数)
- 通算損益 = 現在資産合計 − 初期資産額
- 現在資産合計 = 各参加者の現在資産 + 繰越余剰金
