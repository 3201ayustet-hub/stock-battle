# 株価成長バトル Ver.2.2

## 更新手順
1. SupabaseのSQL Editorで `SUPABASE_UPDATE_v2.2.sql` 全文を実行
2. GitHubリポジトリのWebファイルをこのフォルダの内容で置き換え
3. GitHub Pagesを再読み込み（古い表示の場合はSafariのタブを閉じて開き直す）

## 主な変更
- 保存済み対戦一覧をlocalStorageではなくSupabaseから取得
- 別端末・別ブラウザでも同じ保存済み対戦を一覧表示
- 削除した対戦は再取得後、一覧から即時消去
- 保存済み対戦一覧から直接削除可能
- 対戦未選択の端末では、Supabase上の最新対戦を自動表示
- 4人の状況欄に各参加者の今期成長率を常時表示
- 利確済み参加者の成長率は売却価格で固定

## 計算
- 今期成長率 = (現在値または売却価格 − 取得単価) ÷ 取得単価 × 100
- 今期損益 = Σ((現在値または売却価格 − 取得単価) × 株数)
- 通算損益 = 現在資産合計 − 初期資産額
- 現在資産合計 = 各参加者の現在資産 + 繰越余剰金
