# 株価成長バトル Ver.1.4

## 主な仕様
- 所有株数は1〜10株のプルダウン
- 繰越余剰金は対戦全体で1つだけ入力
- 繰越余剰金は4人の合計資産へ1回だけ加算
- 4人の名前・取得単価・現在値・成長率をコンパクト表示
- 同じ画面に成長率折れ線グラフ
- 対戦設定は後から変更可能
- 新規対戦を作成しても過去の対戦はSupabaseに保存

## 更新方法
1. ZIPとは別に同梱された `SUPABASE_UPDATE_v1.4.sql` をSupabase SQL Editorへ丸ごと貼り付けて1回実行
2. GitHubのファイルをVer.1.4へ置き換え
3. GitHub Pages反映後に `setup.html` を開く

## 資産計算
- 開始時合計資産 = 各参加者の取得単価×株数の合計 + 繰越余剰金
- 現在合計資産 = 各参加者の現在値×株数の合計 + 繰越余剰金
- 個人の成長率 = (現在値 - 取得単価) ÷ 取得単価 × 100
